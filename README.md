# Trade Backtesting System

Trade Backtesting System은 주식 트레이딩 전략을 시뮬레이션하고 분석하는 프로그램입니다.
코딩을 전혀 모르는 분들도 아래 설명을 순서대로 따라 하면 쉽게 사용할 수 있습니다.

## 1. 설치 및 설정 (최초 1회만 필요)

처음 시작할 때 딱 한 번만 다음 과정을 진행해주세요. 컴퓨터 안에 이 프로그램만을 위한 전용 공간(가상환경)을 만드는 과정입니다.
(터미널에서 프로젝트 폴더로 이동한 상태에서 진행해주세요.)

### 1단계: 가상환경 만들기

아래 명령어를 입력하고 엔터를 치세요.

```bash
python3 -m venv venv
```

### 2단계: 가상환경 켜기

방금 만든 공간으로 들어갑니다. **(중요: 프로그램을 실행할 때마다 이 단계를 가장 먼저 해야 합니다)**

```bash
source venv/bin/activate
```

입력 후, 터미널 줄 맨 앞에 `(venv)`라는 글자가 생겼다면 성공입니다.

### 3단계: 필수 프로그램 설치하기

필요한 도구들을 설치합니다. 인터넷 연결이 필요하며 시간이 조금 걸릴 수 있습니다.

```bash
pip install -e .
```

## 2. 프로그램 사용하기

이제 설정이 끝났습니다. 원하는 기능을 실행해보세요.
**(주의: 터미널을 새로 열었다면, 반드시 `source venv/bin/activate` 명령어로 가상환경을 먼저 켜주세요.)**

### 기능 1: 오늘의 매매 신호 확인하기 (Daily Scan)

주요 종목(QQQ, SPY, 테슬라 등)을 분석하여 지금 사야 할지, 팔아야 할지 알려줍니다.

```bash
python scripts/daily_scan.py
```

실행하면 화면에 다음과 같이 나옵니다.

- **UP**: 상승 추세 (매수 고려)
- **DOWN**: 하락 추세 (매도 고려)
- **BUY**: 매수 신호
- **SELL**: 매도 신호

### 기능 2: 과거 수익률 시뮬레이션 (백테스트)

과거 특정 시점부터 투자를 했다면 수익이 얼마나 났을지 계산해봅니다.

기본 실행 (QQQ 종목 기준):

```bash
trade single
```

특정 종목 지정하기 (예: 애플 AAPL, 테슬라 TSLA):

```bash
trade single --ticker AAPL TSLA
```

결과 파일은 `outputs` 폴더 안에 저장됩니다.

### 기능 3: 일괄 백테스트 (Batch Backtest)

나스닥 상위 종목 및 주요 ETF(QQQ, QTUM) 17개 종목에 대해 한 번에 백테스트를 수행합니다.

```bash
python scripts/run_batch_backtest.py
```

실행이 완료되면 `outputs/single/` 폴더에 각 종목별 로그 파일이 생성됩니다.

## 3. 종료하기

사용을 마치려면 터미널 창을 닫거나, 다음 명령어를 입력하세요.

```bash
deactivate
```

## 자주 묻는 질문 (FAQ)

**Q. 'command not found: trade' 라는 오류가 나와요.**
A. 가상환경이 켜지지 않아서 그렇습니다. `source venv/bin/activate` 명령어를 먼저 입력했는지 확인해주세요.

**Q. 3단계에서 설치 중에 빨간 글씨 에러가 떠요.**
A. 인터넷 연결을 확인해주시고, `pip install --upgrade pip` 명령어를 입력해 업데이트를 한 뒤 다시 시도해보세요.
